# 三角洲行动口琴自动扒谱

把 MP3、WAV 或 FLAC 音频文件拖到 `提取口琴谱.bat` 上，即可自动提取适合在《三角洲行动》中演奏的口琴谱。首次运行会建立项目本地环境并下载人声分离模型，因此需要联网，也可能等待较长时间。处理完成后会自动打开 `output` 文件夹。

## 输出内容

每首歌会建立一个同名文件夹，其中包含六类结果：

- 连续按键谱：适合跟随旋律连续演奏。
- 详细节奏谱：按小节和十六分音符格展示节奏、休止与延音。
- 音符明细 CSV：记录时间、原始音高、演奏音高、置信度和游戏按键。
- 主旋律 MIDI：可在编曲或制谱软件中继续编辑。
- 口琴试听 WAV：用于试听移调和量化后的结果。
- 分析报告 JSON：记录速度、移调、音域、音符数等分析信息。

使用 `--keep-stems` 时，还会在 `stems` 文件夹中保留 `vocals.wav` 人声音轨和 `no_vocals.wav` 伴奏音轨。

## 按键标记

数字表示音阶按键，括号表示要同时按住的控制键：

- `5(左)`：演奏数字谱中的 5，同时按住鼠标左键。
- `4(中)`：演奏数字谱中的 4，同时按住鼠标中键。
- `2(右)`：演奏数字谱中的 2，同时按住鼠标右键。
- `1(,)`：这个高音 1 使用键盘逗号键 `,`。

## 命令行用法

在项目目录中运行：

```powershell
.tools\audio-venv\Scripts\python.exe scripts\extract_harmonica_score.py 'D:\Music\song.mp3' --keep-stems
```

默认输出到 `output`，且不会覆盖已有的同名结果。确认需要替换时，加上 `--force`。

## 局限

本工具更适合单人演唱、有明确音高和稳定节拍的旋律。合唱、说唱、强和声或自由节拍素材容易产生误判，生成结果需要人工试听和校对。
