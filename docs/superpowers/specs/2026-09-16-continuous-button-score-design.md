# 《晴天》连续按键谱设计

## 目标

在保留现有详细节奏谱的同时，新增一份可以从头到尾顺着读的《晴天》连续按键谱。谱面不再使用高低音箭头和升号，所有鼠标操作直接写在对应数字旁边。

## 输出方式

- 新增 `output/晴天-连续按键版.md`，不覆盖 `output/晴天-三角洲口琴谱.md`。
- 按歌曲段落换行，段落内连续排列按键。
- 使用全角竖线 `｜` 标记小节边界。
- 保留段落名称和原音大致时间，便于中途定位。
- 连续版只表达按键顺序，不显示延音和休止；节奏练习仍以详细谱为准。

## 记号规则

- 中音白键音：直接写数字，如 `5`。
- 低八度：数字后加 `(左)`，如 `5(左)`。
- 升半音：数字后加 `(中)`，如 `4(中)`。
- 高八度 2–7：数字后加 `(右)`，如 `2(右)`。
- 低八度且升半音：写为 `4(左+中)`。
- 高八度且升半音：写为 `2(右+中)`。
- 高音 1 使用游戏基础键位的逗号键，写为 `1(,)`，不误标为鼠标右键。
- 高音升 1 写为 `1(中+,)`。

## 数据来源与转换

- 以已生成的 398 个主旋律音符为唯一数据源，不重新改音高或节奏。
- 依据每个音符的实际游戏键位生成带鼠标标记的数字。
- 删除延音格和休止格，保留音符的原始先后顺序与小节归属。

## 验收标准

- 连续版音符总数为 398，与详细谱一致。
- 每个连续版音符都能回对到音符明细表中的音高和游戏输入。
- 谱面不出现 `↑`、`↓`或 `♯` 记号。
- 需要鼠标的音符必须在数字后就地显示 `(左)`、`(中)`、`(右)` 或相应组合。
- 高音 1 必须显示为 `1(,)`。
- 原详细谱、MIDI、试听 WAV 和 CSV 保持不变。
